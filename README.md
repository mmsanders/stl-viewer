# Plinth

A phone-friendly STL viewer. Load one or more `.stl` files, keep them on the device, show or hide each part, and orbit or fly around with touch.

Nothing is uploaded. Models stay in this browser.

## Use it

The hosted app is [https://mmsanders.github.io/stl-viewer/](https://mmsanders.github.io/stl-viewer/).

On iPhone, open that link in Safari, tap Share, then Add to Home Screen.

## Develop

```bash
npm install
npm run dev
```

`npm run build:pages` writes the static GitHub Pages site to `dist/client`.
